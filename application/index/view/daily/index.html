阮ㄟ日常

動物照護員 - 彷彿不存在的無名英雄，
在365每天與流浪動物們為伍的工作日子裡，
需要持續站著、彎腰、無私的付出體力，
有時連小歇片刻時間都沒有，
人稱吃力不討好的工作。

儘管如此，我們從這些毛孩們身上學會樂觀，
得到了純粹的滿足，
即便遭遇許多無法用言語形容的辛酸體會，
但毛孩們臉上的笑容卻總是能讓我們忘記生活中的不順遂，促使我們成長、茁壯、堅持下去！

感謝在這片土地，守護流浪動物的愛爸、愛媽和志工們 ;
感謝月園一路走來，不吝伸出援手幫助過我們的善心人士們 ;
感謝阿克影像傳播有限公司無償協助拍攝，將動物照護員的辛苦，細膩的用影像呈現出最真摯的情感與溫度 ;
感謝怕胖團 PA PUN BAND提供歌曲版權，齊心推廣生命教育 ;
感謝參與演出的每一位 ; 沒有你們沒有月園！
