阮ㄟ故事

大家好！我們是

社團法人臺中市
月園流浪動物照護協會

十幾年來，
林媽媽和先生靠著白天工地做工，救援了無數的流浪貓狗，
於民國108年王田交流道附近，
扛下龐大貸款、義無反顧的承租大片土地建設園區！
為的就是提供那些在冰冷長街受到不友善對待的孩子們，一個可以——
不再需要躲藏、不再害怕的避風港-台中林媽媽流浪狗之家！
很快的，園區有越來越多志同道合的年輕人加入林媽媽的行列，
經過訓練成為照護員，像是一家人盡心盡力的一同守護流浪動物，
並在民國110年合法立案『社團法人臺中市月園流浪動物照護協會』

我們致力於—
・ 專業的收容、照護和送養（在這裡每個生命備受重視、獨一無二！）
・ 積極推廣TNVR和生命教育！ — 希望藉著我們的力量，讓台灣成為亞洲地區的動保模範！

園區歡迎大家前來參訪 :
・ 體驗一日義工
・ 認養園區狗狗
・ 接受捐贈物資 — 但因人力有限、照護工作繁瑣，加上園區沒有門牌地址！
以上活動均採預約制，請於線上和管理員先行預約，
無預約者請勿進入感謝您的體諒！
照護流浪動物需投入大量人力、物力，
如果您也認同我們的理念，歡迎捐款用力的支持我們！
